### K35. Dolphin’s Information panel and tooltips show no photo or video details in the sync folder

- **Why:** KDE treats the sync folder as a slow network mount. KDE Frameworks 6.24 classifies a
  FUSE mount without a block device as NFS, and KIO 6.31 marks every `fuse.*` mount whose source
  is not under `/dev/` as slow. Baloo Widgets extracts metadata only for local, non-slow files.
- **Effect:** The Information panel and tooltips show only type, size and dates, cloud-only or
  on disk. **Properties has KOneDrive’s Details tab** for a single photo or video with known
  values: OneDrive’s stored details while cloud-only, and the file’s own details once downloaded.
  The page is omitted when no visible values are available. Indexed columns also stay empty.
- **Stays because:** The panel/tooltip decision is made inside KDE before any extractor runs.
  The `konedrive_mediaextractor` can answer those surfaces once KDE permits extraction of single
  files on slow mounts (draft Baloo Widgets MR 82, KDE bug 452924). The fallback Properties page
  removes itself if KDE supplies its own Details page.
- **Where:** `docs/design/desktop.md` §11.3–11.4; `dolphin/src/detailstab.cpp` and
  `mediaextractor.cpp`; `crates/konedrived/src/mount/item_lookup.rs` (`user.konedrive.media`).
