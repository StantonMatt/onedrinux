### K35. Dolphin shows no photo or video details for files in the sync folder

- **Why:** KDE treats the sync folder as a slow network mount. KDE Frameworks 6.24 classifies a
  FUSE mount without a block device as NFS, and KIO 6.31 marks every `fuse.*` mount whose source
  is not under `/dev/` as slow. Baloo Widgets, which draws the Information panel, tooltips and
  Properties › Details, extracts metadata only for files that are local and not slow.
- **Effect:** The Information panel and tooltips show only type, size and dates for every file in
  the folder, cloud-only or on disk, and the Properties dialog has no Details tab. The daemon's
  `user.konedrive.media` attribute and the `konedrive_mediaextractor` plugin are installed but go
  unused until KDE lets single files on slow mounts be extracted.
- **Stays because:** The decision is made inside KDE before any extractor runs, and no setting,
  mount option or attribute changes it: the kernel fixes a FUSE mount's filesystem type and
  device. The draft Baloo Widgets change MR 82 (KDE bug 452924) would allow extraction of a single
  file on a slow mount.
- **Where:** `docs/design/desktop.md` §11.3; `dolphin/src/mediaextractor.cpp`;
  `crates/konedrived/src/mount/item_lookup.rs` (`user.konedrive.media`)
